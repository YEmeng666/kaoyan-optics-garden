# 考研专业课大观园

物理光学复习工具：从题眼找到模型、第一步、SOP、公式条件和练习入口。

现已提供第 4–8 章的 29 个知识主题、26 类解题方法、32 条公式卡、26 道明确标记的 AI 自拟算例和中文全文搜索。新增内容为按大纲组织的 AI 补充解释，教材章节仅用于复核定位；未声称完成逐页教材校勘或原题答案精校。

## 本地使用（Windows）

1. 从 [Node.js 官网](https://nodejs.org/) 安装 Node.js 22.12 或更高版本。
2. 在这个 README 所在目录打开 PowerShell。首次安装依赖：

```powershell
npm.cmd ci
```

3. 构建完整网站和中文搜索索引，然后预览：

```powershell
npm.cmd run build
npm.cmd run preview
```

打开终端显示的本地地址。预览搜索需先构建；开发时可运行 `npm.cmd run dev`，但开发模式不会自动生成新的 Pagefind 索引。停止命令参照当前终端提示，普通前台会话可按 Ctrl+C。

## 修改一条内容

`/search/` 支持 29 个知识主题的模糊搜索：名称片段、常见译名和英文缩写、空格分隔的组合关键词，以及至少 3 字符名称的一次增删、替换或相邻换位。名称精确匹配优先于简介、正文和近似匹配；近似结果标明匹配依据。相关表述维护在 `content/search-aliases.json`，它们只是检索入口，不表示物理概念完全等价。原有 Pagefind 全文搜索仍保留；扫描 PDF 的正文尚未 OCR 入库。

- `content/knowledge/*.md`：知识正文。以现有文件为模板，保留“一句话、物理图像、条件、易混点、来源”。
- `content/patterns.json`：题型、题眼、第一步、SOP、变式关联、自拟算例。
- `content/formulas.json`：LaTeX、符号、适用条件、误用提示与教材定位。
- `content/course.json`：课程名称、模块与大纲版本。
- `content/supplement.json`：新增章节的知识索引、章节归属与相关真题考点。
- `src/lib/data.mjs`：合并知识主题索引与网址辅助函数。

添加内容后运行 `npm.cmd test` 和 `npm.cmd run build`。ID 必须唯一，关联 ID 必须存在；来源与适用条件不能为空。公式编译成功不等于专业结论正确。

本站典型算例均标为“AI 自拟”，不可去掉标签改称真题。资料库提供历年材料索引与在线试题阅读入口。本次年度试题由项目维护者确认公开；此确认不代表已取得题目著作权或授予再分发许可。新增资料需单独确认公开范围。

## 资料库

历年题目是主要练习来源。`/questions/` 提供 400 条逐题分类记录（399 条汇编／回忆记录及 1 条辅助近似题），覆盖 15 个年份，按年份、原题号、叶书第 4–8 章、考点、题型筛选。首页、各章及解题方法均优先连接真题；26 道 AI 自拟算例作为辅助检查保留。

`content/questions.json` 保存概括标题、分类、原册题号、PDF 页序、版本与缺题标记。保留回忆版跳号和缺题，不补造内容；2023 计算3原文明确是近似题，默认真题结果将其排除。整题各子问归在同一条目中。参考答案目前只定位到年度范围，不声称完成逐题答案勘误。统计数量表示分类记录，不能直接当作真实考频。原题正文与图可直接打开年度 PDF 阅读，入口自动把原汇编页序转换为年度文件页序。

29 个知识点页面均内置一条例题和一道课后自测。例题与课后题是为本站原创的 AI 自拟题，不照抄教材题干；每一步都标明“做什么、为什么、得到什么”，并给出结果检查。历年真题仍单独标注年份并打开原卷。练习内容维护在 `content/knowledge-practice.mjs`，新增知识点时必须同时补齐例题、课后题与逐步理由。

`/library/` 收录 8 份 PDF 元数据：试题汇编、配套第三方参考答案、4 份补充练习及 2 本教材。2008–2016 年试卷扫描、2018–2023 年回忆版按年度与答案页配对；2017 年单列为考点示例，2024 年占位通知和封面营销年份不计作真题。

16 份年度试题 PDF（2008–2023，共 87 页，2017 为考点示例）随站点提供，且保存在公开 GitHub 仓库的 `public/materials/exams/`。`content/cloud-library.json` 记录逐文件哈希与原册页码映射。年度文件来自原汇编相应页面，不包含前言、占位通知或其他附件。

答案、教材和补充习题仍通过本机连接阅读。在页面选择本机 PDF（支持多选），浏览器按文件大小和 SHA-256 识别正确版本，然后生成带页码的本机阅读链接。文件不会上传或保存到云端；当前会话有效，刷新后需重新选择。移动端 PDF 阅读器可能忽略页码锚点，此时按入口标出的 PDF 页序手动跳转。答案内容尚未逐题校核，扫描题目不在全文搜索范围内。

`content/library.json` 保存资料名称、文件指纹、页数、年度页码与核查状态，不含本机路径。更换资料版本后须重新核对页码并更新指纹；不能仅改文件名或沿用旧页码。

## 发布

本项目输出静态 `dist/`，不需要数据库、付费 API 或自建服务器。

### GitHub Pages

当前线上站点由 Sites 提供；GitHub 保存公开源码和年度试题，尚未启用 GitHub Pages。以下为自行启用的步骤。换用其他域名时，同时更新 `content/cloud-library.json` 中的 `baseUrl`。

源码附带 `.github/workflows/deploy.yml`。在仓库 Settings → Pages → Build and deployment 选择 **GitHub Actions**。启用 Pages 后，在 Actions 页面手动运行该工作流，它将安装锁定依赖、执行数值与内容检查、构建并发布。

工作流会自动为普通项目仓库设置 `/<仓库名>/` 基路径；若仓库名为 `<用户名>.github.io` 则使用 `/`。页面、字体、搜索资源和站内链接均使用同一基路径。

### Cloudflare Pages 或其他静态托管

连接本仓库，构建命令填 `npm run build`，输出目录填 `dist`，Node.js 使用符合 package.json 要求的版本。默认根路径部署；自定义域名时设置 `SITE_URL` 为真实地址。源代码仓库是私有的，不代表网页也是私有的；需要私人使用时必须配置托管平台访问控制。

### Sites

当前工作副本可通过 Sites 发布；`.openai/hosting.json` 只有站点标识和静态输出目录，不含访问凭据。复用模板时删除旧的 project_id 并为自己的新站点注册，不要向原站点部署。

## 内容与隐私边界

发布范围为本站程序、原创重述、自拟模型算例、公开引用信息以及本次已确认公开的 16 份年度试题。校验程序只放行清单中哈希完全匹配的年度 PDF。不要将教材 PDF、购买讲义、其他未确认公开的扫描资料、个人错题、审计附件、账号凭据或本机路径复制到此仓库。`public/` 中的文件会直接公开下载。

`.gitignore` 是预防措施，不能撤销已经被提交的文件。每次推送前在 GitHub Desktop 或 `git status` 中检查待上传列表。程序与内容的开放许可尚待项目维护者明确；当前公开可见不代表已授予 MIT 或其他复用许可证。

## 出处与核查

依据电子科技大学 2026 版 840 大纲组织，主要引用叶玉堂等《光学教程》第 2 版第 4–8 章，辅助引用赵凯华《新概念物理教程·光学》相关章节。教材并未随站点分发。新招生届次的大纲需另行核对。详情见网站“资料依据与内容说明”。

## 备份和恢复

公开程序通过 Git 提交保存。修改前先提交一个可用版本；出错可在 GitHub Desktop 查看历史并恢复文件。私人资料单独备份，不进入本仓库；本版尚无个人错题与学习进度数据库。
